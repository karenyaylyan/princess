# Квест на день рождения 🎂

Готовая игра: 6 уровней, буквы-клетки, кнопка подсказки, переход между уровнями, финальный конверт со ссылкой на подарок. Вёрстка оптимизирована под вертикальный мобильный экран (формат 9:16) — открывать лучше всего с телефона.

## Что нужно сделать перед отправкой

### 1. Замени иллюстрации
Сейчас в `images/level1.svg` … `images/level5.svg` лежат нейтральные заглушки (река/мяч, каска и соусницы, щёчки, зайка, граф) — без чьих-либо лиц, просто чтобы игра сразу работала и была видна тема каждого уровня.

Когда сделаешь финальные иллюстрации (у художника, в удобном тебе генераторе изображений, или сам нарисуешь) — просто положи файлы в папку `images/` и в `script.js` укажи их пути:

```js
const LEVELS = [
  { image: "images/level1.png", word: "ХАЧИК" },
  ...
];
```
Формат (png/jpg/svg) и пропорции — любые, я поставил рамку 4:3, но она подстроится.

### 2. Ссылка на подарок уже вставлена
В `script.js` уже стоит твоя ссылка (Яндекс.Диск):
```js
const GOOGLE_DOC_URL = "https://disk.yandex.ru/i/CX6ikZG2aXFxoA";
```
Просто проверь перед отправкой, что доступ к файлу на Яндекс.Диске открыт по ссылке (не приватный).

### 3. Проверь текст
- Заголовок сверху ("Загадай желание…") и текст в финальном окне ("С днём рождения, любимая!") — в `index.html`, можешь поменять на её имя/что-то более личное.

## Как захостить на GitHub Pages
1. Создай новый репозиторий на GitHub (можно приватный, если не хочешь, чтобы кто-то ещё это увидел — но учти: приватные репозитории GitHub Pages работают только с платным аккаунтом; для публичного всё бесплатно).
2. Залей туда все файлы из этой папки (`index.html`, `style.css`, `script.js`, `images/`).
3. В настройках репозитория → Pages → Source выбери ветку `main` и папку `/root`.
4. Через минуту-две сайт появится по адресу вроде `https://твой-логин.github.io/название-репозитория/`.
5. Скинь эту ссылку девушке в день рождения 🎉

## Как это работает
- Правильно введённые буквы (или открытые подсказкой) закрепляются зелёным/розовым и не сбрасываются.
- Неправильные при проверке очищаются, можно пробовать снова.
- Прогресс сохраняется в браузере (localStorage), так что если она случайно закроет вкладку — не потеряет прогресс на этом же устройстве.
- Значок ↺ в правом верхнем углу — сбросить прогресс для тестирования. Можешь удалить кнопку из `index.html`, если не нужна.

Проверь сам весь квест перед отправкой — открой `index.html` в браузере (просто дважды кликни файл) или через GitHub Pages ссылку.
